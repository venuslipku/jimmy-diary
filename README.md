# Jimmy Diary

Personal notes site, published with GitHub Pages at <https://venuslipku.github.io/jimmy-diary/>.

Every page has a `noindex` tag, so search engines like Google won't list it.

## Adding a new article

1. Put the article in its own folder, e.g. `My_topic/README.md` (plus any other `.md` pages it links to).
2. Add one line to `index.md`:
   ```
   - [My Topic](My_topic/) Short description.
   ```
3. Commit and push. The site updates in a minute or two.
